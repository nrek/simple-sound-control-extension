# Support

## Quick help

- **Remove the extension:** `chrome://extensions` → find *Simple Sound Control* → **Remove**.  
- **Pin to toolbar:** Extensions puzzle icon → pin *Simple Sound Control*.  
- **Delete saved URLs / tabs:** Open the popup → **gear (Settings)** → *Saved volume states* → **URLs** or **Tabs** → trash icon.  
- **Boost above 100%:** Can cause **distortion or clipping**; lower the slider if audio sounds harsh.
