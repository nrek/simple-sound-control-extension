# Security Policy

## Supported versions

We address security issues in the **latest release** published on the Chrome Web Store (or the `main` branch of this repository, whichever you are asked to use internally).

## Reporting a vulnerability

**Please do not** open a public GitHub issue for unfixed security vulnerabilities.

1. **Preferred:** Use [GitHub Security Advisories](https://github.com/nrek/simple-sound-control-extension/security/advisories/new) for this repository *if* that feature is enabled for the repo.  
2. **Otherwise:** Contact **[Craft & Logic](https://craftxlogic.com/contact)** with a clear subject (e.g. “Security: Simple Sound Control”) and enough detail to reproduce or understand the impact.

Include:

- Affected version / commit  
- Steps to reproduce (or proof-of-concept)  
- Your assessment of impact (confidentiality / integrity / availability) if you can  

We will acknowledge receipt as soon as we can and work on a fix or mitigation in private before public disclosure where appropriate.

## Scope

This policy covers **this extension repository** (popup, background service worker, content scripts, and packaging). It does **not** cover third-party websites you browse while using the extension, the Chrome browser itself, or unrelated Craft & Logic products—use the appropriate channel for those.

## Safe harbor

We support good-faith security research that follows this disclosure process and does not intentionally harm users or data.
